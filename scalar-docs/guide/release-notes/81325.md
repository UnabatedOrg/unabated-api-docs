# 8/13/25

### Breaking Changes

**No breaking changes in this release.**

### Realtime API / WebSocket Updates

* `event`**&#x20;updates now include&#x20;**`seasonId`**&#x20;and&#x20;**`seasonPartId`

* `marketLineUpdate`**&#x20;events now include a&#x20;**`marketTypeId`**&#x20;on the container**

  * You may see more granular "buckets" of updates

  * You may now filter your websocket subscription by `marketTypeId` if needed

  * All lines within the update are of the same `marketTypeId`

  * You can find `marketTypeId` options using the REST `/market-type` service

### REST API Updates

#### New Endpoints

* **Season Information**

  * `/season/{league}`

* **Tournament Information**

  * `/tournament/{league}`

* **Market Type Options**

  * `/market-type`

* **Period Type Options**

  * `/period-type`

* **League Options**

  * `/league`

#### Updated Endpoints

* `/player`

  * Now includes `teamId` for each player

  * Now includes `modifiedOn`, and the ability to query `changedSince`

* `/event`

  * Now includes `seasonId` and `seasonPartId` for each event

  * Now includes `modifiedOn`, and the ability to query `changedSince`

* `/team`

  * Now includes `modifiedOn`, and the ability to query `changedSince`
